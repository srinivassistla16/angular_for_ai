r_splitter = RecursiveCharacterTextSplitter( chunk_size=70, chunk_overlap=10, separators=["\n\n", "\n", " ", ""] ) split_lst = r_splitter.split_documents(docs)

The text file when loaded by TextLoader , it will have 1 document in the list (i.e. docs). Usually the chunk size and chunk overlaps are higer say 500 chars in the real time production systems.

This docs list is splitted as 70 chars - parts with overlap of 10 chars. This over lap helps in healing the broken sentenses.

NOTE : There are multiple types of text splitters in Lang Chain. While the splitting algorithm is different for different splitter the interface methods are same. So onlt RecursiveTextCharacterSplittr is demonstrated here.
